WHY NEWSMARKER

公众号日更的痛，不是「没得写」，
而是「写得慢、配图烦、发得乱」。

刷 40 个站点攒素材、开文档拟大纲、让大模型写稿再手动排版、找封面图、去后台粘贴——这一套动作每天重复三遍。Newsmaker 把这些动作收进一个本地工作台：

  • 1

    攒素材不靠人肉——RSS / 网页 / JSON / Changelog 四类源统一接入，72 小时窗口自动抓取，按「官方源 + 实体热度 + 时效性」规则打分排序，非官方媒体图只作预览、绝不进发布位。

  • 2

    AI 只做初稿，人做终审——选题可改、草稿可改、标题可换、图片可换，每次改动自动留版本快照；生成的每一段素材都带来源与评分证据。

  • 3

    发布不靠复制粘贴——微信走官方草稿箱接口一键同步；小黑盒走富文本复制 + 半自动浏览器导入，停在人工审核位，系统永不自动点发布。

技术栈

克制的老实组合：一个脚本语言生态、一个 Web 微框架、一个原生 JS 工作台、四个外部协议。任何一层都能看懂、能替换。

Python 3.12Flask 3Jinja2原生 JS 单页工作台 httpxfeedparserBeautifulSoup4PyYAML PillowPlaywrightSQLiteJSON 数据层 OpenAI 兼容 LLM API阿里云 DashScope 文生图微信公众平台 API抖音开放平台

设计与工程上的三个坚持

  • 官方接口优先：微信走 draft/add 草稿箱接口，抖音走开放平台授权，小黑盒无公开接口就停在人工审核，不做模拟登录与逆向。
  • AI 永远不是最后签名的人：所有生成内容可编辑、可回滚、留版本快照；配图带审核证据，选题带事实清单。
  • 本地即云端：单机可跑、密钥不出门、数据全备案，方便你随时备份或迁移到自己的服务器。
QUICKSTART

五分钟，把编辑部开到本机

需要：Python 3.12+、一个任意厂商的 OpenAI 兼容大模型 Key（DeepSeek / GLM / 通义等均可）。微信同步需服务号 / 订阅号 AppID 与 AppSecret。

  1. 1

    克隆并安装依赖
    git clone https://github.com/RoyZ1/newsmaker.git && cd newsmaker && pip install -r requirements.txt

  2. 2

    配置密钥——把 LLM_API_KEY / LLM_MODEL_ID / LLM_BASE_URL 填进 .env（可选的微信 / 图模型 / 抖音 Key 见 docs）。

  3. 3

    跑起来——python run_server.py，打开 http://127.0.0.1:5050（端口默认 5050，可在 .env 的 APP_PORT 调整）。

  4. 4

    点一下「开始采集」——等评分列表刷新，即可进入选题与写作。想调整信息源就编辑 config/sources.yml。

  5. 5

    （可选）小黑盒半自动导入——python -m playwright install chromium 后即可在草稿卡片使用。

# config/sources.yml —— 新增一个信息源只需十行
- id: qbitai_feed
  name: QbitAI
  type: rss
  enabled: true
  url: https://www.qbitai.com/feed
  tags: [media, china, ai]
  include_keywords: [AI, 大模型, 智能体, DeepSeek]
  keyword_scope: title   # 中文媒体：只按标题过滤
  max_items: 10
# 写作提示词也是配置文件，随你调教文风
config/prompts/article_writer.json   # 长文草稿
config/prompts/title_writer.json     # 标题改写
config/prompts/humanizer_zh.md       # 中文「人味化」规则
config/prompts/cover_image_prompt.json # 配图提示词
