# 小黑盒图文稿（标题 + 正文 + 配图位）

## 标题（≤30 字，含前缀时请自行精简）

`我开源了个"AI 科技小编"，把新闻自动写成稿`（21 字；系统会自动加前缀，若超 30 字请删前缀）

## 正文（配图顺序：①总览大图 ②选题页 ③草稿配图页 ④发布记录页）

做内容最烦的从来不是"写"，而是写之前和写之后的一堆搬运活：刷几十个站攒素材、拟选题、让 AI 出初稿、再手动找图排版，最后还要一个个平台复制粘贴。

这套流程我重复到烦，索性写了个开源项目 **Newsmaker**，把"素材 → 选题 → 写作 → 配图 → 发布"串成一条**本地运行的流水线**。它不替你签最后一个字，但把重复劳动基本消灭了。

## 01 选题：AI 帮你把"一堆新闻"变成"值得写的角度"

内置 37 个科技 / AI / 游戏信息源（OpenAI、Anthropic、DeepMind、华为、智谱、DeepSeek 官方源 + 国内外媒体 + arXiv + GitHub 热榜），自动抓最近 72 小时内容，按官方源、头部公司、模型发布、时效性打分排序。

跑完采集，AI 会把当天素材按实体聚成**候选选题卡**——每条都带标题、角度、结构提纲和引用素材，人工可改可删。选题不再靠"刷到什么是什么"。

## 02 草稿与配图：AI 打稿，图片槽位自动排好

写稿支持公众号长文、短文、小黑盒三种文体；输出会过结构化校验，不合格自动带问题清单修复重试，不会硬塞烂稿。

更省心的是配图：系统按章节规划**图片槽位**，候选来自官方原图、AI 生图、官方页面截图和手动上传四条路，每张图过"清晰度 / 水印 / 重复"审核后才能进发布位。标题也能批量改写选最优。

## 03 从草稿箱到发布：只走官方接口，人工把关

微信侧直接调公众号官方 `draft/add` 接口，图片压缩、缩略图素材、整稿提交一步到位；小黑盒没有公开草稿接口，就做成**半自动浏览器导入**——像现在这篇一样，标题正文自动填好、图片按位置插好，停在编辑页等你审核保存，**绝不替你点发布**。

舆论素材也可以采：抖音开放平台授权接口抓公开评论，自动排成评论卡片图，再生成"舆论与争议"章节。

## 最后：它是什么，不是什么

一切跑在本地 `127.0.0.1`，密钥只存在你自己电脑的 `.env`（已加进 `.gitignore`）；不模拟登录、不碰平台风控；AI 只做初稿，**署名和发布权永远在你手里**。

技术栈很朴素：Python + Flask + 原生 JS 工作台，采集用 feedparser / BeautifulSoup，AI 走任意 OpenAI 兼容模型，浏览器自动化用 Playwright，数据 JSON + SQLite 双轨留痕。克隆后五分钟能跑起来，提示词全是可编辑的配置文件，能调成你自己的文风。
